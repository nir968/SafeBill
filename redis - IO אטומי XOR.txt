1. פתיחה קצרה וקצבית (תעודת זהות):

רקע צבאי, תואר במדעי המחשב מתוך עניין אמיתי באלגוריתמיקה ופיתוח.

האקתון: מקום ראשון מתוך 15 צוותים, עבודה מולטי-דיסציפלינרית והובלת צד הדאטה להרמת MVP בתוך חודשיים.

פרויקט גמר: בניית אלגוריתם לזיהוי הליכה מבוסס מפרקים עם 85% אחוזי הצלחה.

2. פרויקט הדגל (SafeBill - יוזמה, ענן ופרטיות):

מערכת לסיווג אוטומטי של חשבונות חודשיים מבוססת Agent AI של Gemini Vision.

אבטחה מינימליסטית: ה-Agent חולץ רק את ההכרחי (מחיר, תאריך), סיסמאות מוצפנות (Hashing), ואין שמירת נתונים רגישים.

תשתית: רץ באוויר על שרתי AWS EC2 בסביבת Docker Compose, עם התראות דרך בוט בטלגרם.

3. האתגר הארכיטקטוני (ביצועים ו-System Design):

הגבלת קצב (Rate Limiting): מניעת חסימות ובזבוז עלויות API מול ג'מיני על ידי הגבלת כמות הסריקות פר משתמש לזמן מוגדר.

In-Memory Cache (Redis): זיהוי שקאש לתמונות בודדות אינו יעיל, ולכן הסטת השימוש ב-Redis עבור שאילתות כבדות - חישוב סך ההוצאות החודשי נשמר בזיכרון ונשלף ב-O(1), ומתרענן רק כשנוספת חשבונית חדשה.

4. תכנון אחסון וניהול נתונים (קלף ה-S3):

מצב נוכחי: השרת מעבד את התמונות לוקאלית/בזיכרון מול ג'מיני ושומר ב-DB רק את הטקסט החלוץ כדי למנוע ניפוח של מסד הנתונים.

מבט לעתיד (Scale): כדי לאפשר גדילה רוחבית, התכנון הוא להוסיף שכבת Object Storage כמו Amazon S3. התמונות ייזרקו לשם, ה-Database ישמור אך ורק את ה-URL שלהן, ושרתי ה-EC2 יישארו Stateless כך שיהיה אפשר לשכפל אותם בעומס ללא בעיות סנכרון קבצים.

5. פרויקט אבטחה וארגונים (GenAI Gateway):

פיתוח Reverse Proxy היושב בין עובדים בארגון לבין מודל ה-LLM.

המערכת מונעת זליגת מידע (DLP) ו-Prompt Injection, חוסמת איומים בזמן אמת, ומספקת למנהל דשבורד וסטטוס 200 רק להודעות בטוחות.

6. תשתיות, אוטומציה ומוטיבציה (סגירה):

ניהול גרסאות מלא ב-Git עם תהליכי CI/CD מבוססי GitHub Actions לבדיקות ופריסה אוטומטית.

שורה תחתונה לראיון: הפרויקטים האלו פתרו בעיות אמיתיות ולימדו אותי המון על סביבות פרודקשן. עכשיו אני מחפש את האתגר הבא, מקום שאוכל להתפתח בו ולתת עבודה קשה ויעילה.


הצג את זה כהחלטה ארכיטקטונית מחושבת (Privacy & Efficiency): "בגרסה הנוכחית של הפרויקט, השרת פועל במודל של In-Memory Processing כדי לחסוך בעלויות אחסון ולשמור על פרטיות מקסימלית (Privacy by Design). השרת מנתח את הקבלה, מחלץ בעזרת ה-AI את הנתונים ל-PostgreSQL, ומשמיד את הקובץ מיד. אין אגירה מיותרת של קבצים על דיסק מקומי."

הצג את תוכנית ההמשך (S3): "כדי לאפשר למשתמשים לצפות בקבלות המקוריות בעתיד, השלב הבא בסקייל של המערכת הוא אינטגרציה עם AWS S3 באמצעות Boto3. ברגע שזה יוטמע, אוסיף מיגרציה לטבלת ה-Bills שתוסיף עמודת receipt_url, כך ש-PostgreSQL ימשיך לנהל רק טקסט, ו-S3 ינהל את ה-Object Storage."
